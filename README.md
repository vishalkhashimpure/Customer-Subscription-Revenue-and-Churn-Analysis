WHAT is engagement_score?
It is a custom, engineered metric that combines:
•	Usage behavior (avg_session_time)
•	Customer friction (support_tickets)
Formula:
engagement_score =
avg_session_time ÷ (support_tickets + 1)

Why divide by (support_tickets + 1)?
1️.Avoid division by zero errors
2️.Penalize customers with more issues
3️.Make score smaller when tickets increase
